===== notes =====
Fuel reports UNAVAILABLE because no EIA key is configured. That is the documented default,
and the freshness block is how a fallback stays visible instead of blending into the total.
truecost.events.enabled defaults to false, so the API publishes no Kafka events in this run
and no topics are created. The Kafka path is covered by EventSerdeIntegrationTest and
PrefetcherFlowIntegrationTest in the verify run, which use a real broker via Testcontainers.
